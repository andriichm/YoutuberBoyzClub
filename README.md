# YoutuberBoyzClub

Сайт клуба ютуберов: https://andriichm.github.io/YoutuberBoyzClub/

## Как редактировать

Всё содержимое (участники, видео, соцсети) лежит в файле [`data.js`](data.js):

- **Участники**: имя, роль, тема, ссылка на канал, аватар.
- **Видео**: вставьте `id` из ссылки YouTube (часть после `watch?v=`).
- **Соцсети**: пустые ссылки на сайте не показываются.

После изменений сделайте commit и push, и сайт обновится примерно через минуту.
